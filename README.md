## 기능 목록

### 1. 입력 구현 (클래스 이름:`InputController`)
- [X] 구입 금액을 입력받는다.
- [X] 당첨 번호(구분자: 쉽표)를 입력받는다.
- [X] 보너스 번호를 입력받는다.

### 2. 로또 발행 구현 (클래스 이름:`LottoMachine`)
- [X] 사용자가 입력한 금액에 따라 로또를 발행 후 출력한다.

### 3. 로또 일치 구현 (클래스 이름:`Lotto`)
- [X] 당첨 번호와 일치 개수를 계산하는 기능을 수행한다.
- [X] 보너스 번호와 일치하는지 확인하는 기능을 수행한다.

### 4. 출력 구현 (클래스 이름:`OutputController`)
- [ ] 구매한 로또 개수 및 각 로또의 번호를 출력한다.
